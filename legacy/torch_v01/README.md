# Legacy PyTorch v0.1 implementation

These files are preserved unchanged for history and forensic comparison with the original
`v0.1.0-alpha` release. They are not part of the installed `vla_fastvlm` package, are not
imported by the active MLX code, and require the old PyTorch/Transformers/LeRobot stack.

Do not use these scripts for the MLX research. The active entry points are in `scripts/` at
the repository root. Their continued presence is **not** evidence that PyTorch remains a
supported training or inference backend.
